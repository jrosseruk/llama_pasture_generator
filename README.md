# Llama Pasture Generator

![AgentBreeder Poster](thumbnail.png)

## Overview

This project generates pasture visualizations filled with llamas, as featured in the AgentBreeder research poster.

## About AgentBreeder

**AgentBreeder: Mitigating the AI Safety Risks of Multi-Agent Scaffolds**

Research by J Rosser and Jakob Foerster from the University of Oxford.

The poster visualization features a fun challenge:
- **Guess the number of Llamas!** 🦙
- **Find the secret sheep!** 🐑
